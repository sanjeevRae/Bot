# Chitra AI Chat — WordPress Plugin

Add the Chitra AI assistant chat widget to any WordPress site in one click.

## Install

1. Zip the `chitra-ai-chat` folder (or upload the folder to `wp-content/plugins/`).
2. In WP Admin go to **Plugins** and activate **Chitra AI Chat**.
3. Go to **Settings → Chitra AI**, paste your **Org ID** from the Chitra dashboard, and save.

The chat widget now appears on every page of the site.

## Settings

| Field | Description |
|---|---|
| Org ID | Your Chitra organization ID (Dashboard → Install on your site) |
| API URL | Your Chitra backend URL. Default: `https://chitra-ai-backend-p6ex.onrender.com` |
